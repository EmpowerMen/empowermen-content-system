# Idea Bank

Status: scope agreed, not yet built. Built per pillar as each pillar's first piece is chosen, Warrior and King first.

## What already exists

Book notes in `foundations/sources/books/` carry file-level tags and archetypes in their frontmatter, and most hold record-level entries with tags and archetypes. They do not need re-tagging.

## What is missing

- The 13 Moore transcripts in `foundations/robert-moore-lectures/transcripts/` have summaries but no quote-level tags.
- A few book files hold one record or none (Corneau, Bly, Michler).
- No tag records the shadow pole, the problem phrase a man would search, or whether a line has been checked against the audio.

## The shelf

One file per pillar (`warrior.md`, `king.md`, then `magician.md` and `lover.md`). Each entry points to an existing record or transcript passage and adds only the missing fields.

| Field | Meaning |
| --- | --- |
| Source | File and record or timestamp |
| Line or idea | The verbatim words, or a short paraphrase marked as such |
| Energy and shadow pole | For example King, Tyrant (inflated) or Weakling (deflated) |
| Problem phrase | What a man would type into a search box |
| Best format | Short, carousel, X post, email quote, Skool prompt |
| Verified | Checked against the audio or the book text: yes or no |

## Rules

- Moore lines come only from the real transcripts, never from the README or template sample text, and are checked against the audio.
- Credit the right author. The Pilgrim's Questions are Sam Keen's, from *Fire in the Belly*.
- Paraphrase is marked as paraphrase and is not used as a quote.
